    START WITH A NOTE
    先记录，再分析
    1. 新建一次实验
      选择课程或课题，自由书写；需要报告结构时切换模板。没有照片或试剂盒也可以记录。
    2. 边做边留下过程
      正文和未提交的过程草稿会自动保存。点击“添加过程记录”后进入带本机时间的时间线；关闭前请确认“已保存”。
    3. 保留原始附件
      添加多张照片、CSV、PDF 或 Office 文档，单个不超过 20 MB。原件不被分析工具覆盖。
    4. 按需关联分析
      可从照片或 CSV 附件开始。先确认实际方法、数据是否模拟及处理参数，再保存分析快照。软件不自动生成实验结论。
    5. 复盘与带走资料
      写下结果和下一步，完成后设为只读；补充需填写修订原因。支持资料包导出、报告打印、回收站与全量备份。
    这是个人本地预览版，不自动上传云端。自动保存不是备份，修改历史也不是合规电子签名。请定期导出到另一块磁盘，不要把重要资料只放在这一台电脑上。

    QUICK START
    一次分析，五个步骤
    1. 导入原始照片
      从官方 App 保存眼镜照片后传入电脑，尽量保留未经二次修图的文件。也可先载入演示。
    2. 框选有效液体
      点击“框选区域”，拖拽画矩形。也可点击“添加测量区域”，在坐标框内调整。避开管壁、液面和反光。
    3. 指定一个对照组
      点击右侧样本，设为对照。教学与科研模式共用计算方法，科研模式展示更完整的数据。
    4. 查看颜色与质量提示
      点击“开始分析”。RGB 为通道中位色，HSV 由该中位色转换；Lab 为逐像素转换后的通道中位数。两两 ΔE₀₀ 越小，图像颜色越接近。质量提示不能代替人工复核。
    5. 保存可追溯的记录
      点击“保存与导出”，保存本地记录并下载 ZIP。记录包含原图、标注图、CSV、JSON 与 SHA-256 校验清单。
    照片默认按 sRGB 解释，未进行色卡或设备校准。模糊提示也可能由均匀溶液触发；软件不自动剔除反光像素。仅用于教学科研辅助，不用于临床诊断。
    快捷操作：Esc 取消框选 · Delete 删除选中区域（文本框内除外）· 所有区域均可用坐标输入修改。
